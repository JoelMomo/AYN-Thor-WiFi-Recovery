# Changelog

A short, user-facing changelog for the public AYN Thor projects.

## 2026-09-18

### Thor Wi-Fi Recovery — 0.3.0-beta15
- Marked `0.3.0-beta15` as the latest signed public prerelease.
- Finalized the polished two-column Thor layout and typography.
- Expanded and validated the interface across 12 languages.
- Added physical-device screenshots and the `+ apps` discovery route.
- Kept the app offline: no Internet permission and no telemetry.

### RuneBoard — Prototype 0
- Validated the core IME architecture on physical AYN Thor hardware.
- Confirmed lower-display use, direct touch input and D-pad + A/B/X/Y typing.
- Confirmed L1/R1 cursor movement, opacity switching and minimize/restore.
- Core architecture is validated; product/visual development remains in progress.

## 2026-09-16

### CarePad — modular foundation
- Continued the modular CarePad shell architecture.
- Active modules cover Performance, Games & BIOS, and Controls.
- Project remains in active development and is not presented as a finished release yet.
